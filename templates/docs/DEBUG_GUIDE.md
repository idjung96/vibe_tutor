# 문제가 생겼을 때

1. logs/app.log 파일을 메모장으로 엽니다.
2. 맨 아래에서 위로 올라가며 ERROR 를 찾습니다.
3. ERROR 줄의 | 뒤에 있는 값(예: user_id=15)이 문제가 생긴 입력입니다.
4. 그 줄을 통째로 복사해서 AI에게 붙여넣고
   "이 에러 고쳐줘"라고 하면 됩니다.

로그 형식이 정해져 있어서, ERROR 한 줄만 주면
AI가 어디서, 무엇을 하다가, 어떤 값 때문에 실패했는지 모두 알 수 있습니다.

## 그래도 안 되면
- 화면에 보이는 에러 메시지를 그대로 복사해서 AI에게 주세요.
- "언제부터 안 됐는지"를 한 줄 덧붙이면 더 빨리 찾습니다.

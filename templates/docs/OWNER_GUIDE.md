# 사용 안내 (Owner용)

당신이 할 일은 3가지뿐입니다.

## 1. 시작할 때
Claude Code(또는 사내 AI 코딩 도구)를 이 폴더에서 열고
"개발 시작"이라고 입력하세요.
AI가 몇 가지를 물어봅니다. 번호나 짧은 답으로 답하세요.
계획(team/PLAN.md)을 보여주면 읽어보고 "1"을 입력하면 개발이 시작됩니다.

## 2. 질문이 올 때
개발 중 중요한 결정이 필요하면 team/OWNER_QUESTION.md 파일이 생기고
개발이 멈춥니다. 파일을 열어 보세요.
- 선택지마다 영향 표가 있습니다.
- "되돌리기" 줄을 특히 보세요. "불가"인 선택은 신중하게.
- 맨 아래 "답:" 뒤에 번호를 적고 저장하세요. 예) 답: 2
- 조건을 붙이고 싶으면: 답: 2. 보관 기간은 90일로
저장하면 개발이 자동으로 이어집니다.

## 3. 끝날 때
요구사항별 통과 표를 보여줍니다.
프로그램을 직접 실행해 보고 원하는 대로 되는지 확인하세요.

## 문제가 생기면
team/guides/DEBUG_GUIDE.md 를 보세요.

## team/ 폴더의 파일들 (에이전트 작업 기록)
- team/PLAN.md : 개발 계획 (쉬운 말 요약)
- team/DECISIONS.md : 지금까지 내려진 결정들
- team/TEST_LOG.md : 테스트 현황 (숫자가 계속 늘어나면 정상)
- team/libs/INDEX.md : 이 프로그램이 쓰는 외부 도구 목록

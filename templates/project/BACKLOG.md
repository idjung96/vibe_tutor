# 백로그 (에이전트 협업용)

에이전트들이 나중에 처리할 일과 참고 메모를 여기에 모은다.
이 파일은 메인 세션만 쓴다. subagent는 자기 출력에 "BACKLOG: 설명" 한 줄로
후보를 내고, 메인 세션이 아래에 옮겨 적는다.

## 할 일 (actionable)
형식: - [ ] B-번호 설명 · 출처:stageN/역할 · 우선순위:상/중/하
완료하면 [x]로 바꾸고 줄 끝에 "→ stageN 처리"를 적는다.

## 메모·주의 (참고 — 처리 대상 아님)

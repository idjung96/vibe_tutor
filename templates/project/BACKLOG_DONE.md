# 백로그 — 완료 이력 (아카이브)

완료된 백로그 항목을 여기로 옮긴다. **추적성 보존용이고 새 작업은 여기에 쓰지 않는다.**

왜 나누나: BACKLOG.md 는 planner·coder·designer·lead 가 매 단계 읽는 파일이다.
완료 항목까지 쌓이면(실측 프로젝트에서 891줄·119KB) 그만큼 호출마다 딸려 간다.
**지우는 것이 아니라 옮기는 것이다** — 어떤 지적이 언제 왜 처리됐는지는 남아야 한다.

옮기는 시점: 단계 merge 뒤(12번). `[x]` 로 바뀐 항목을 이 파일 끝에 붙이고
BACKLOG.md 에서 지운다. 형식은 그대로 둔다.

형식(완료): - [x] B-번호 설명 · 출처:stageN/역할 · 우선순위:상/중/하 → stageN 처리
형식(폐기): - [-] B-번호 설명 · 출처:stageN/역할 · 폐기:stageM · 사유: 한 줄

**폐기는 삭제가 아니다.** 안 하기로 한 것도 기록이다 — 나중에 같은 항목이 다시 올라오면
"그때 왜 안 했나"를 여기서 찾는다. 사유는 넷 중 하나여야 한다:
이미 해결됨 / 요구사항이 바뀜 / 다른 항목에 흡수됨 / 재현 안 됨.
"안 할 것 같아서"는 사유가 아니다. 출처가 Owner인 항목은 팀이 스스로 폐기하지 않는다.

# 테스트 해제 목록

**커밋된** 테스트 파일은 `protect_tests.sh`/`guard.js` 가 수정을 막는다. 여기 적힌 것만
예외로 통과한다. 미커밋(추적 안 되는) 테스트는 여기 안 적어도 고칠 수 있다 —
방금 자기가 만든 것이니까.

형식(경로와 **같은 줄**에 `근거:` 가 있어야 유효하다):

```
- tests/test_payment.py · 근거: 픽스처가 실제 버그를 동결했다(B-295)
```

- `근거:` 가 없는 줄은 **무효**다. 무엇을 왜 푸는지 적히지 않은 해제는 해제가 아니다.
- 이 파일을 읽지 못하면 전면 동결한다(빈 목록으로 보지 않는다).
- 고치고 나면 그 줄을 지운다. 해제는 **한 번 쓰고 버리는 것**이지 쌓는 목록이 아니다.
- 판단이 서지 않으면 여기 적지 말고 C등급으로 Owner 에게 물어라.
